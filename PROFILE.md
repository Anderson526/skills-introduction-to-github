# GitHub Fundamentals

Welcome to my GitHub profile!

## Key Concepts

### Pull
Pulling retrieves the latest changes from a remote repository and merges them into your local branch. It keeps your local copy in sync with the remote.

### Push
Pushing uploads your local commits to a remote repository, sharing your changes with others.

### Merge
Merging integrates changes from one branch into another, combining the histories of both branches.

### Fork
Forking creates a personal copy of someone else's repository, allowing you to freely experiment with changes without affecting the original project.
